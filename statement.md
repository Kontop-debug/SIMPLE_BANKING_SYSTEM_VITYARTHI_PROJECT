# Problem Statement

## Python Bank Management System

Develop a **console-based Bank Management System using Python** that allows users to manage bank accounts and perform basic banking operations.

The system should allow a user to:

* Create a new bank account by providing the account holder's name and an initial deposit.
* Automatically generate a unique 10-digit account number.
* Access an existing account using the account number.
* Deposit money into an account.
* Withdraw money from an account while checking for sufficient funds.
* Check the current account balance.
* View account details.
* View the complete transaction history.
* Close an existing bank account after confirmation.
* Exit the application safely.

The system should also perform basic input validation, such as preventing empty account names, negative initial deposits, invalid menu choices, and withdrawals that exceed the available account balance.

The application should use **Object-Oriented Programming (OOP)** concepts with separate `Account` and `Bank` classes. Account information and transaction records should be maintained during program execution.

## Objective

The main objective of this project is to develop a simple banking application that demonstrates **Python classes, objects, methods, dictionaries, conditional statements, loops, exception handling, and random number generation**.

## Scope

This project is intended as an **educational banking system** for demonstrating basic Python programming and OOP concepts. Account information is maintained only while the program is running and is not stored in a permanent database or file.
